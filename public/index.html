Setup

Configure your .env file before first run. All values are required unless marked optional.

MORALIS_API_KEY
Web3 Data API key from moralis.com. Free tier works — keep POLL_INTERVAL_SECONDS at 600 to stay within rate limits.
X_CONSUMER_KEY
X_CONSUMER_SECRET
App credentials from X Developer Portal. The app must have Read and Write permissions.
X_ACCESS_TOKEN
X_ACCESS_SECRET
Access token and secret for the X account that will post. Generate these under Keys and Tokens in the Developer Portal.
ADMIN_PASSWORD
Password for this dashboard. Choose something strong — there is no second factor.
POLL_INTERVAL_SECONDSoptional
How often to poll for new sales. Default: 600. Lower values consume more Moralis API quota. Free tier: keep at 600+.
DRY_RUNoptional
Set to true on first run to log tweets to console instead of posting. Toggle live/dry mode from the header once running.

Phrases

One phrase per line. They rotate in order — one phrase is prepended to each sale tweet. Leave empty for plain tweets.
